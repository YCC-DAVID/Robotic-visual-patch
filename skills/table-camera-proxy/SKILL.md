# 桌面与相机的粗估计

目标是得到各视角的 `K`、`T_camera_from_table` 和 `H_table_xy_m_to_image_px`，让同一张物理纹理在共享桌面坐标中投影。当前适配器覆盖 G1 三路 640×480 的单帧，以及物体静止的短视频窗口；场景参考为立方体＋已知上沿边。

先阅读 [pipeline 与输入约定](references/pipeline.md)。它说明已实现步骤、命令、输出、检查方法及多帧扩展边界。

## 执行

1. 在用户指定工作区查找包含 `realprobe/run_table_proxy_pipeline.py` 的 WAMattack 根目录。当前工作区路径为 `/home/user1/workspace/chence/WAMattack`；可按实际位置调整。此 skill 依赖该仓库的实现与本地数据，不携带私有视频或模型权重。
2. 根据请求选择范围。只问进度时，读取已保存的几何与 `pipeline_status.json`；请求复现或估计时，先核对尺寸、角点、图像及当前适配器范围。
3. 使用 `--plan` 查看执行计划，再运行新目录中的几何流程。使用具备 NumPy、SciPy、OpenCV、PyAV、Pillow 的解释器；成像还需 PyTorch。当前可用环境与命令见参考文档。
4. 默认单帧几何；前 15–20 帧联合估计使用 `--num-frames 20`，先检查所选窗口中方块与容器保持静止。每路共享内参，每帧分别求位姿。单帧可选 `--with-imaging`、`--with-edge-blur`；多帧入口当前只做几何。缺少 RoboTwin 捕获不应阻塞纯几何步骤。
5. 检查优化收敛、重投影及叠图。单帧另有排除残差和先验敏感性诊断；多帧检查跟踪、有效帧覆盖、四点低冗余帧及 1／15／N 帧对照。成像步骤还检查梯度和 resize。报告适用的 episode/frame、假设与结果文件。

## 几何中不能混淆的约定

- 已知边长提供尺度；使用完整立方体的顶面、侧面和接触点，比只拟合一个面更能约束粗模型。当前 5.2 cm、10.5 cm 是本项目用户给定值，换场景要读新记录，不能照搬。
- 三路中的同一角点 ID 必须对应同一物理点。无纹理方块有旋转对称性，不能把各视图的“左上角”独立当成同一点。
- 桌面为局部 `Z=0`；方块顶面在一个边长的高度上。测得的容器边是**后部上沿外边**，其高度要拟合，不能当桌面，也不能据一条边虚构完整正方形开口。
- `T_camera_from_table` 将桌面坐标转换为相机坐标；相机中心是 `-R.T @ t`，不是 `t`。`H` 的输入是**米**，输出是原图像素。
- 当前主点居中、`fx=fy`、零畸变是拟合先验。重投影残差小不代表完整内参已经标定。
- 同一物理 patch 共享世界位置、尺寸、方向和纹理；对内容做透视，不能只用梯形 mask 裁切未变形的纹理。

## 保持任务范围

当前用户选择：先做粗桌面投影，新增实拍暂缓，成像可借用 RoboTwin。若 patch 投影与操作相关的机械臂、夹爪、被操作物体或目标容器重叠，则需要按前后关系处理遮挡；先用逐相机、逐帧的前景／可见性 mask 即可，并记录 patch 可见面积。无遮挡区域沿用平面代理，不把完整三维重建、精确手眼标定或 IK 作为启动门槛。

第 19 页的固定示例使用 `realprobe/render_table_occlusion_preview.py`。第 20 页的 `realprobe/sequence_render_proxy.py` 已将 episode 18 的 0–19 帧、6 cm patch、中心附近 2 cm／±30° 的局部前景 mask 接入训练；仍非任意场景的通用遮挡。换位置或轨迹须重新检查可见性，不能直接照搬这组颜色阈值。训练入口及原模型配置的剩余不确定性见参考文档第 10 节；仅在用户要求训练时使用，普通几何估计不自动启动训练。

短窗口的 `H_t` 已实现 LK 跟踪与联合位姿估计；不能用短窗口成功声称整段视频可用。各路内参在窗口中共享，世界坐标不随腕部移动重置。抓起方块后不能继续将它当作固定桌面参考，需要换静止目标或另建物体运动模型。

连续帧的跟踪共享初始标点偏差；低残差不等于独立验证。四个非共面点可以在共享内参／场景约束下支持位姿，但冗余少，必须如实记录。当前 1／15／N 对照使用同一组亚像素修正起点，与旧手工单帧结果的差异不全来自帧数。

RoboTwin 响应是借用先验；边缘拟合混合了物体轮廓、插值、模糊和压缩，不能直接宣称为相机光学 PSF。pipeline 的 `succeeded` 只表示程序与实现检查完成，不表示实物验证、策略训练或 ASR。
